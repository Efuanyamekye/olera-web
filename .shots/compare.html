What the render caught that two code reviews did not

1
The page states a number it then contradicts. "4 providers on Olera near Dallas" sits above a list of three. The count reads the full array; the list slices to three. Nobody saw it in the diff. One screenshot did.
2
Preview isolation does not exist. resolveCityLandingArm returns an assigned flag and the page throws it away, so ?v= writes the cookie and fires events like real traffic. The PR body claims otherwise. That claim is false, and taking row one's screenshots wrote events.
3
The control's progress counter regressed. The four-question flow now reads "Step 4 of 5". It read "Step 4 of 4" before this branch touched it. A regression in the control is the worst place to put one.

Two of those three came from the other reviewer. The first came from looking at the page. That is the argument for a render gate in front of every design change.

Reading the two rows

Row one's first and third frames are the same page with different words. Same headline treatment, same button, same provider list in the same place. Only Providers first changes what is on screen, so two of those three arms would take a third of the traffic each to test a copy change.

Row two changes what a visitor can do, not what they are told. Browse first lets someone explore a provider before giving anything up; Conversation first deletes the quiz entirely. Those are different products, not different headlines, which is what makes them worth a third of the traffic each.

The honest split: row one has the machinery that row two does not — server-side assignment, one URL so the live ads are never touched, and the arm stamped on every event so the read never depends on a reconstruction. Row two has the design. The build worth shipping takes the first from row one and the second from row two.

What neither row can settle. At roughly thirteen visits per arm per day, six arms cannot be ranked against each other. This picks a direction, not a winner, and any two frames that both produce starts will be indistinguishable at this volume.
