# Sources

Primary source material for the MedJobs operating model. **These are inputs, not decisions.** Where they
conflict, `../07-OPEN-DECISIONS-AND-CONFLICTS.md` names the conflict; where a conflict is resolved,
`../06-DECISIONS.md` records the resolution.

## Why these are distilled rather than committed raw

The Zoom transcript is ~1,450 lines and covers benefits, SEO, tooling, and unrelated business alongside
MedJobs. The distillation keeps every decision-bearing statement, quotes verbatim where the exact wording
matters, and attributes each position to a speaker — because several items are one person's view rather than
a group decision. The raw transcript and the original PDF live with the session that produced them.

## Adding a source

1. Distil it here — decisions, quotes, and who said them. Attribution matters.
2. Diff it against the current protocols and decisions.
3. **Any conflict goes into `../07-OPEN-DECISIONS-AND-CONFLICTS.md` before anything is changed.**
4. Only then update a protocol, and log the change in `../08-ITERATION-LOG.md`.

Never silently reconcile a new source against an existing protocol. The conflict is the information.
